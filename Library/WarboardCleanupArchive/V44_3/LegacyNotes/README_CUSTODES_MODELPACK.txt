INSTALL
1. Extract this ZIP directly into the root of the Warboard Unity project.
2. Run INSTALL_CUSTODES_MODELPACK.bat once.
3. Open the project in Unity and allow it to import the OBJ/texture assets.
4. Test a Custodes roster.

The installer only patches ModelVisualRegistry.Resolve() and creates a .custodes-backup first.
The existing Aeldari model pack is left intact.

TTS Custom_Assetbundle-only entries are not part of this OBJ/texture pack.
See Assets/Resources/Armies/Models/Custodes/CATALOGUE.txt for the indexed object list and any missing cache URLs.
