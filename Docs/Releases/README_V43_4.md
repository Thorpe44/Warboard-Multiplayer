# Warboard v43.4 — Custodes Badge Position Hotfix

Fixes the locked Adeptus Custodes detachment status bar being drawn across the
middle-left of the battlefield.

The Custodes badge now uses the same top-right status stack as the Aeldari
badge. If an Aeldari locked badge is already present, Custodes automatically
takes the next row beneath it.

The label also includes the player/faction slot for consistency, e.g.:

`Player 2 • ADEPTUS CUSTODES • Lions of the Emperor • 2/2DP • Disruption • LOCKED`

Visible build marker: `WARBOARD v43.4`.
